### 🚀 关于我 (About Me)

我是 **王定方**，一名专注于 **AI Agent、算法开发与高性能软件** 的跨学科工程师。拥有 测控技术与仪器 / 生物技术与工程 的复合工程背景，在 **单细胞/空间组学大模型算法、HPC 集群管理及 AI Agent 工作流搭建** 方面积累了丰富经验。目前致力于将大语言模型（LLM）与系统级开发结合，构建生产级的智能体与高效算法系统。

- 🤖 **方向焦点：** 自主 AI Agent 开发、多模态与图算法（Graph/Spatial Algorithms）、LLM Workflow。
- 🛠️ **系统与工程：** HPC 集群运维管理（Slurm, Docker, Singularity）、C++/Python 高性能计算与私有镜像部署。
- 💡 **技术转轨：** 融合深度学习、空间计算与软件架构，打造低延迟、高可扩展的 AI 与软件产品。
